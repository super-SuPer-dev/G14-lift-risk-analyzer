G14 Lift Risk Analyzer - prototype เว็บแอป (Streamlit)

วิธีรัน
  pip install -r requirements.txt
  streamlit run app.py
แล้วเปิด http://localhost:8501

ไฟล์
  app.py             หน้าเว็บ: อัปโหลดคลิป (หรือเลือกคลิปตัวอย่าง) + ส่วนสูง + น้ำหนักของที่ยก -> ผลวิเคราะห์
  liftrisk_core.py   โค้ดคำนวณ สร้างอัตโนมัติจาก G14_LiftRisk_Realtime.ipynb ด้วย tuning/gen_core.py
                     (แก้ที่ notebook แล้วสร้างใหม่ อย่าแก้ไฟล์นี้ตรง ๆ)
  model/             โมเดล Workshop12 ของกลุ่ม + ไฟล์ประกอบ
  models/            โมเดล MediaPipe pose
  samples/           คลิปตัวอย่าง 2 คลิปของ G14_S03

หมายเหตุ
- ต้องใช้ OpenCV 4.x (OpenCV 5 จะ error ตอนวาดตาราง)
- ถ้ามี ffmpeg แอปจะแปลงวิดีโอเป็น H.264 ให้เล่นในเบราว์เซอร์ได้ ถ้าไม่มีให้กดดาวน์โหลดไปเปิดเอง
- แอปคัดลอกไฟล์ไปทำงานในโฟลเดอร์ temp ของเครื่อง เพราะ MediaPipe เปิดไฟล์ในพาธภาษาไทยไม่ได้

โหมดการทำงาน
- อัปโหลดไฟล์ / คลิปตัวอย่าง : เห็นภาพผลลัพธ์ขยับทีละเฟรมระหว่างประมวลผล แล้วสรุปผลเมื่อจบ
- กล้องสด                   : ใส่หมายเลขกล้องของเครื่องที่รันแอป (0 = ตัวแรก) หรือ URL ของกล้อง IP
                               มีเวลานับถอยหลังให้เดินไปยืน แล้ววิเคราะห์ตามเวลาที่ตั้ง จากนั้นสรุปผล

ความเร็ว (วัดบนเครื่องของกลุ่ม ใช้ CPU, ภาพ 720x1280)
- วาดตารางเอียงในฉาก     ประมาณ 14 เฟรม/วินาที (ช้ากว่าเวลาจริง)
- ปิดตารางเอียง (ค่าตั้งต้นของกล้องสด เหลือตาราง 2 มิติมุมจอ)   ประมาณ 37 เฟรม/วินาที
- ผ่านหน้าเว็บ ภาพ 1080x1920 ปิดตารางเอียง   ประมาณ 24 เฟรม/วินาที

ข้อควรรู้ของกล้องสด
- โมเดลเทรนจากวิดีโอ 30 เฟรม/วินาที ถ้าเครื่องประมวลผลได้ช้ากว่านั้น การเคลื่อนไหวต่อเฟรมจะมากกว่าตอนเทรน
  และหน้าต่าง 60 เฟรมจะกินเวลานานกว่า 2 วินาที ผลการนับรอบอาจเพี้ยน ให้ดูตัวเลขเฟรม/วินาทีใต้ภาพ
- ยังต้องยืนตรงนิ่งช่วงแรกเพื่อ calibrate และ 60 เฟรมแรกโมเดลยังไม่ทำนาย
- โหมดกล้องสดทดสอบแล้วด้วยไฟล์วิดีโอที่ป้อนแทนกล้อง ยังไม่ได้ทดสอบกับเว็บแคมจริง
